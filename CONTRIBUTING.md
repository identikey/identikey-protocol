# Contributing to IdentiKey Protocol

Contributions to this repository use the [Developer Certificate of Origin 1.1](DCO.md). Sign every commit with a `Signed-off-by` trailer by creating it with:

```bash
git commit -s -m "Your commit message"
```

A contribution without a `Signed-off-by` trailer is not accepted.

There is no Contributor License Agreement (CLA) for this repository. The product CLA in `identikey-core` does not apply to `identikey-protocol`.
