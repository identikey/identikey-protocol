# Learnings

- 2026-09-01: This repo's spec surface is `docs/standards/`, not `openspec/specs/`. Folding a change archives it under `openspec/changes/archive/` and leaves the living spec in `docs/standards/`.
- 2026-09-03: Desktop-v1 "REK" (32-byte master in macOS Keychain, Argon2 wrap fallback, HKDF `IdentiKey/item-v1` + ChaCha20 persona envelopes in SQLite) does **not** want a new crate. Map it onto the existing split: `identikey-wallet` already is the local at-rest master (IKEYW v2 = Argon2id + XChaCha20-Poly1305 file; OS keychain caches the 32-byte derived key via `CredentialProvider` / `security_framework::passwords` in `crates/identikey-wallet/src/credential.rs`). Persona items are wallet identities (`WalletIdentity` + Gordian Envelope), not SQLite blobs. Shared wrap-to-members is `identikey-keyspace-v1` (PUK / PTK), not REK. Hardware-bound keys are `identikey-auth`. Recrypt only adds PRE assertions on the same wallet (`recrypt-cli/src/wallet/mod.rs`). identity-manager's `SecKeychain` sketch is deprecated API; do not copy it into this crate — steal biometric-on-read intent, implement on `CredentialProvider`. Local v1 code (unpublished): `IdentiKey-Desktop-original` branch `identikey-desktop-v1`.
