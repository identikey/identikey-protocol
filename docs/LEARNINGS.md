# Learnings

- 2026-09-01: This repo's spec surface is `docs/standards/`, not `openspec/specs/`. Folding a change archives it under `openspec/changes/archive/` and leaves the living spec in `docs/standards/`.
- 2026-09-03: Desktop-v1 "REK" (32-byte master in macOS Keychain, Argon2 wrap fallback, HKDF `IdentiKey/item-v1` + ChaCha20 persona envelopes in SQLite) does **not** want a new crate. Map it onto the existing split: `identikey-wallet` already is the local at-rest master (IKEYW v2 = Argon2id + XChaCha20-Poly1305 file; OS keychain caches the 32-byte derived key via `CredentialProvider` / `security_framework::passwords` in `crates/identikey-wallet/src/credential.rs`). Persona items are wallet identities (`WalletIdentity` + Gordian Envelope), not SQLite blobs. Shared wrap-to-members is `identikey-keyspace-v1` (PUK / PTK), not REK. Hardware-bound keys are `identikey-auth`. Recrypt only adds PRE assertions on the same wallet (`recrypt-cli/src/wallet/mod.rs`). identity-manager (deprecated `SecKeychain` sketch) was deleted 2026-09-03; biometric-on-read, if wanted, belongs on `CredentialProvider`. Local v1 code: `Archive/identikey-desktop-v1` (branch `identikey-desktop-v1`, tag `desktop-v1`, `ac139dd`). GitHub `identikey/IdentiKey-Desktop` archived 2026-09-05 after that push; `main` there is Tabula Rasa.
- 2026-09-03 Sol consult (`sol-arch-review`, caution): do not resurrect REK. Call the IKEYW key a **wallet-scoped at-rest key**, not a general local master — it replaces REK only while all local secrets live in the wallet. PUK/PTK are a different layer (multi-holder distribution). Real gaps that are not a new crate: optional deep-lock as a nested assertion; biometric ACL on `CredentialProvider`; device-key cascade is a keyspace lifecycle hole, not a missing REK. Tradeoff: whole-file AEAD makes backup simple and grows unlock blast radius.
